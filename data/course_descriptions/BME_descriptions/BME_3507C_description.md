# BME 3507C — Course Description

Subject: BME | Course: BME 3507C

BME 3507C
 Signals Syst Bioengineers - 3 credits(s)
 Introduction to analysis of signals arising from both living and non-living systems. Basic processing of signals with emphasis on processes for linear systems. Includes Laplace and Fourier transforms and use of computers for signal and system analysis within bioengineering applications.
 Prerequisite(s)
 MAC 2312 for level Undergraduate with minimum grade of C and ( PHY 2049C for level Undergraduate with minimum grade of C or ( PHY 2049 for level Undergraduate with minimum grade of C and PHY 2049L for level Undergraduate with minimum grade of C ) ) and EGN 1041C for level Undergraduate with minimum grade of C and BME 3403C for level Undergraduate with minimum grade of C
