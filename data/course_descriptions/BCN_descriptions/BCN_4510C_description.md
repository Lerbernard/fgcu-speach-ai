# BCN 4510C — Course Description

Subject: BCN | Course: BCN 4510C

BCN 4510C
 Mechanical Systems - 3 credits(s)
 Principles and practices of building piping systems, hydraulics and pumps, comfort conditioning systems for building, heating and refrigeration equipment, building code considerations, plan reading and cost estimation.
 Prerequisite(s)
 ( ( PHY 2053 for level Undergraduate with minimum grade of C and PHY 2053L for level Undergraduate with minimum grade of C ) or ( PHY 2053 for level Undergraduate with minimum grade of C and PHY 2048L for level Undergraduate with minimum grade of C ) or PHY 2053C for level Undergraduate with minimum grade of C ) and BCN 4612C for level Undergraduate with minimum grade of C
