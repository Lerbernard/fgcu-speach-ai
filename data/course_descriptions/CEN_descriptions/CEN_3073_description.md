# CEN 3073 — Course Description

Subject: CEN | Course: CEN 3073

CEN 3073
 Requirements Engr & Analysis - 3 credits(s)
 Covers the analysis of software requirements, and the study of requirements engineering tools and techniques. Includes requirements elicitation, gathering, formalizing, specification, and validation.
 Prerequisite(s)
 CEN 3031 for level Undergraduate with minimum grade of C and ( STA 2037 for level Undergraduate with minimum grade of C or STA 2023 for level Undergraduate with minimum grade of C )
