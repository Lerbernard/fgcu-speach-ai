# COP 4020 — Course Description

Subject: COP | Course: COP 4020

COP 4020
 Principles of Programming Lang - 3 credits(s)
 This course covers programming language theory and practice, including language design and implementation, theoretical foundations, language translators and interpreters, and exposure to a variety of programming paradigms.
 Prerequisite(s)
 COT 4420 for level Undergraduate with minimum grade of C and CEN 3031 for level Undergraduate with minimum grade of C and COP 3530 for level Undergraduate with minimum grade of C
